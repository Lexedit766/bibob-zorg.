# Bibob voor zorgaanbieders

Statische website (GitHub Pages) van mr. J. Smit, jurist, over de Wet Bibob voor zorgaanbieders: uitleg, begeleiding en cursussen.

- `index.html` – homepage
- `bibob-onderzoek.html` – pijlerpagina Bibob-onderzoek
- `assets/style.css` – stijl
- `kennisbank.html` en 20 themapagina's (belang van de toets, situaties, wetgeving, regio's)
- `_build/` – generator: `python3 _build/pages.py && python3 _build/pages2.py` (vanuit `_build/`)
- `sitemap.xml`, `robots.txt`, `404.html`
